*Requests: A library used to make HTTP requests to connect and call the Facebook Graph API.  tkinter: A library used to build the graphical user interface (GUI) for the application.  Built-in standard Python libraries: http.server, json, os, random, threading, time, datetime, urllib.parse, and webbrowser
* Required libraries and installation:
* You need to install the requests library using the command pip install requests and ensure your Python environment has tkinter available (on Ubuntu/Debian, you may need to install sudo apt install python3-tk).
* Preparation steps:
* You must prepare your Page ID and Page Access Token for the Fanpage, up to 5 sample post contents, and a folder containing random images or video files on your computer.
* Usage and operation:
* Run the source code file using the command python3 fb_autopost.py, enter the configuration parameters into the application interface, save the configuration, and click the "Start" button to let the system automatically run the loop of posting according to the scheduled time.[cite: 1]
